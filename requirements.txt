# Pin philosophy: lower bounds keep us above known-buggy versions; we

# Pillow<12, pytest<9) cause pip to try downgrading + rebuilding from
# source — which fails on Python 3.13 due to missing build backends
# (mesonpy). Phase 3b-fixup-1 relaxed all upper bounds; revisit if a
# real breaking change in a major version shows up.
